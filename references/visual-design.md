# 正式场景的视觉设计

## 选型

先确定本页重点与核心关系，再选组织方式。复用现有 layout 记录，简单页面无需补充无关字段。

| 核心关系 | 优先形式 | 要表达的信息 |
|---|---|---|
| 顺序、决策 | 流程、泳道 | 方向、分支条件、责任与结果 |
| 层级、架构 | 分层、分区 | 包含关系、接口与必要边界 |
| 传播、反馈 | 路径、闭环 | 来源、去向、阻断或反馈位置 |
| 阶段、依赖 | 时间轴、阶段带 | 顺序、依赖与进入条件 |
| 数值、变化 | 原生数据图表 | 数值、单位、尺度与来源 |
| 精确对照 | 表格、对齐条目 | 可比较维度与差异 |
| 核心判断 | 重点文字配解释或局部图示 | 主次层级与支撑依据 |

图形承担关系解释；图标辅助识别；插画用于有实际作用的场景表达。资料中没有的流程、比例和边界保持未知，不为填满画面补造内容。

## 构图与风格

沿用模板固定区、字体层级与主色，正文根据内容采用主图配解释、主次分栏、上下层级或必要的网格。连续同类页面可维持统一结构；内容关系变化时重新选型。

节点按角色区分，尺寸和位置表达层级。有向关系使用箭头；双向关系在确有依据时表达。跨区连线优先直角绕行，标签与线分离，连接可独立追踪。复杂关系可分成总览和细节页。

全套统一图标、线宽、箭头与强调方式。强调色用于重点、风险或状态，并配文字或符号。装饰与图案少量使用，服从模板与阅读需求。结构图形、连线、表格与数据图表采用原生对象；照片、插画和装饰资产可用图片。

## 试制与复核

代表页覆盖实际出现的复杂关系或密集信息风险；已有同条件证据可复用。先检查关系、层级与可读性，再批量制作。

最终渲染检查：重点是否清楚，方向、分支、边界是否完整，连接是否可追踪，文字是否清晰，固定区是否保留。联系表检查整套节奏；布局重复只作线索，以内容关系是否得到表达为判断依据。

缺失或错误的关系、不可读及遮挡必须修复。层级不清、机械重复或装饰干扰按实际影响处理。记录具体页、问题及修正证据，沿用现有 QA 分类；全部必需检查完成后再生成通过状态，后续修改使相关检查失效。
